# ShadowPlay

ShadowPlay — експериментальний настільний ігровий лаунчер для Windows на Win32 API. Інтерфейс має темне оформлення, а бібліотека формується зі знайдених ярликів Windows.

## Можливості

- Сканування ярликів `.lnk` на робочому столі та в меню «Пуск» (для поточного й загального профілів).
- Отримання цільового шляху ярлика через COM `IShellLink`.
- Список знайдених ярликів, запуск подвійним клацанням або кнопкою.
- Повторне сканування бібліотеки.
- Без сторонніх runtime-бібліотек: Win32 API, Shell API та COM.

## Збирання EXE

### Варіант 1: Visual Studio

Потрібен Visual C++ із Windows SDK, що містить заголовки й бібліотеки Win32. Для цільової сумісності з Vista використовуйте x86 Native Tools Command Prompt і задайте підсистему Windows 6.00.

Запустіть у корені репозиторію:

```bat
build.bat
```

Готовий файл: `build\ShadowPlay.exe`.

### Варіант 2: CMake

Використовуйте генератор Visual Studio та платформу Win32:

```bat
cmake -S . -B build -A Win32
cmake --build build --config Release
```

Вихідний файл буде в каталозі `build\Release\ShadowPlay.exe` (залежить від генератора).

## Сумісність

Код обмежує цільові макроси рівнем Windows Vista (`_WIN32_WINNT=0x0600`, `WINVER=0x0600`) і використовує базові Win32/Shell/COM API. Це не є підтвердженням фактичної роботи на Windows Vista: потрібне збирання відповідним x86 toolchain та тестування на справжній Vista або сумісному середовищі. Сучасні версії Visual Studio можуть не підтримувати Vista як цільову ОС.

Рекомендований історичний інструментарій — Visual Studio 2010/2012 з x86-компілятором і відповідним Windows SDK; фактичний результат залежить від встановленого SDK та налаштувань лінкера.

## Обмеження поточної версії

- В бібліотеку потрапляють ярлики, для яких Windows Shell може визначити цільовий шлях. Це не повноцінне виявлення встановлених ігор.
- Запуск виконується через сам ярлик, щоб зберегти аргументи та робочу директорію, задані в ньому.
- Наразі немає обкладинок, категорій, збереження вручну доданих записів чи перевірки, чи є ціль саме грою.
- Список використовує стандартний елемент керування Windows; оформлення карток буде вдосконалюватися в наступних версіях.
